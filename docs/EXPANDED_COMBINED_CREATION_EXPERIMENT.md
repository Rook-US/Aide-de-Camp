The player loaded Test 14 and supplied paused manual save `Save8_10_2026_21_28_59`, labeled **ADC Test 14 - Paused**. The player visually confirmed Zouave on the new infantry and Cold Steel on the new cavalry. ADC reloaded the game-written save and passed **27 focused checks**: all eight uniquely identified units retained their explicit parents, branch, weapon, strength, faction, and home state; each has one complete four-field-linked path; all three requested stock arrays survived unchanged; both perk triples survived; the new infantry retained saved experience `50` with zero separate unspent perk progress; and the game regenerated complete `armygrouprefs.dat` counts. The game may renumber saved unit IDs, so these checks resolve current IDs from the game-written identity and parent records.

The player reported that `ADC Batch New Experience` displays **two stars** and **“Battle Experienced”**, while the perk action says **“Not enough experience to select perk.”** This is consistent with the installed game code: `ImportExportUnitData.OverwriteUnits` divides saved regiment experience by 100, so saved `50` becomes runtime `0.5`; `BattleUI.UpdateUnitPanelCampaign` displays `floor(Regiment.Experience() × 5)`, yielding two stars. The installed campaign tooltip table calls that rating “Battle experienced.” `Regiment.ChoosePerk` instead requires an empty perk slot whose separate `Perk.perkexp` is at least `1`; this unit's empty first slot is `(-1,0,0)`. **Unit experience and unspent perk progress are separate saved fields.** A starting experience value of 50 does not grant a perk choice.

These game results support the eight exact 1.142 combinations tested, including the displayed experience tier and both starting skills.
