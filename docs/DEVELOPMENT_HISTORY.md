# Development history

Aide-de-Camp began as GTCW.OOBEditor. This repository retains the original public starter commits (`b28a6b2` and `7b9f3f5`) in its Git ancestry. Most subsequent work was developed in local versioned folders. The milestones below document that work; they are not separate historical Git commits.

The 0.8.4–0.8.10 series was prepared during the October 5, 2026 development session, building on the earlier army/roster editing foundation.

| Version | Main development milestone |
| --- | --- |
| 0.8.4 | Faction navigation and management expansion groundwork. |
| 0.8.5 | Management UI refinements, wider UI settings ranges, and error logging. |
| 0.8.6 | Treasury controls and recruitment-state filtering. |
| 0.8.7 | Nation management: subsidy funding, projects, and policies. |
| 0.8.8 | Project category boards, stage interactions, and near-complete policy progress. |
| 0.8.9 | Officer fame and attributes, ship readiness controls, and management batch editing. |
| 0.8.10 | Aide-de-Camp branding, MIT licensing, public developer documentation, and portable Windows distribution. |

The 0.8.9 baseline passed 277 service checks and 632 UI checks in the local validation environment. That included read-only inspection of nine available campaign save directories. Original game saves were preserved. These results establish an automated baseline, not proof that every edited campaign effect has been accepted by the running game.

Future development should use ordinary focused commits and release notes. Known uncertainty belongs in mapping comments, tests, and the known-limits document so new contributors can distinguish verified storage behavior from campaign behavior still needing confirmation.
