# Contributing

See [BUILDING](docs/BUILDING.md) for local setup and verification. Open a focused issue or pull request describing the problem, resulting behavior, and relevant checks.

For save mappings, document the enclosing section, record identity, units, valid range, and evidence of how the campaign consumes the value. Use synthetic fixtures in the repository. Distinguish storage round trips from in-game acceptance. Keep unknown values unchanged and retain backup, undo, and conflict checks.

For UI changes, exercise the actual WPF view, including resizing, validation, mixed batch values, and selection retention when relevant. Keep implementation details out of ordinary user controls.

Do not upload game files, assets, binaries, decompiled source, personal saves, logs, credentials, or machine-specific paths. Describe evidence without redistributing proprietary material. Contributions are accepted under the project's MIT license.
